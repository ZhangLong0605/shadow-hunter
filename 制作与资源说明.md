# 制作与资源说明

## 作品范围

《影子猎手 · 月蚀森林》1.0 是完整的单章节桌面单人游戏：包含教学、自由试炼、五境连续探索、三项任务、构筑成长、营地存档、两阶段首领、黎明与同化结局，以及失败重试。

本次完善基于项目小组已有的 0.8 源码，保留夺影、三槽技能与梦蚀机制。没有增加多人、随机世界或额外章节，也不把这些列为已完成功能。

## 1.0 增加与完善

- 月蚀森林标题插画、重排标题菜单与操作入口。
- 角色、月狼、森林树木、地表细节及环境光粒的程序化绘制。
- 为菜单、营地、探索、战斗、首领、胜利及失败编写旋律与和声，使用 Web Audio 本地合成播放。
- 音乐/音效独立音量、静音、亮度、镜头震动、环境动画设置。
- 旅人/猎人两档难度，旅人将玩家受伤乘以 0.65。
- 猎人纪事、六项成就、通关次数与最佳时间；与旧营地存档隔离。
- 暂停摘要、退出/重开确认、章节结尾文案与鸣谢。
- 无需开发环境的便携单文件 HTML 与打包脚本。
