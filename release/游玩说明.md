# 影子猎手 · 五境远征 1.4

单人、桌面键鼠操作的动作探索游戏。夺取敌人的能力，选择一种技能，探索五个独立世界并收集专属战利品。

## 直接开始

- 源码文件夹：双击「开始游戏.html」，或打开 dist/index.html。
- 便携发布版：双击「影子猎手-直接玩.html」。所有程序、画面和配乐均在这个文件中，可离线运行，不需要 Node.js、Unity、Godot 或安装依赖。
- 推荐使用新版 Microsoft Edge 或 Chrome，电脑横屏，1366×768 或更大窗口。浏览器需要允许 JavaScript。
- 点击「开始旅程 · 含教学」。第一次点击或按键后，浏览器才允许播放音乐；如果没有声音，检查右上角音符、游戏设置与系统音量。
- 想先看全部技能，可进入「月下试炼场」。试炼不会受伤，也不会影响正式旅程的营地存档。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标 | 瞄准 |
| 左键 / J | 普攻；左键长按 0.5 秒后松开为蓄力攻击 |
| R | 近战刃形与远程弓形切换 |
| 空格 | 闪避 |
| Q | 释放当前装备的技能 |
| 长按 E | 靠近白色暴露敌人，持续约 1 秒夺影；受伤会打断 |
| Tab | 免费更换技能；面板内 Tab 切换焦点，Esc 关闭 |
| F | 与附近任务地点、补给箱或营火互动 |
| C | 使用月露药剂，回血并净化梦蚀 |
| B | 随时开启传送，静止 3 秒返回初始营地，自动保存并结算 |
| M | 打开全图，选择追踪地点；不会传送 |
| N | 打开五境星图；在安全营地或通关后前往已解锁世界 |
| 滚轮 / − / + / 0 | 调整大地图视野；0 复位 |
| Esc | 暂停或关闭部分面板 |

## 怎样通关

1. 教学中学会攻击、夺影、装备与释放技能。
2. 从守夜营地出发，沿北方石路寻找斥候。击破后停下攻击，长按 E 夺取弓手影，按 F 开箱。
3. 自由安排顺序完成破镜小径的追猎、余烬庭院的守灯、缚影祭坛的指定夺影。每次任务成功选择一项祝福。
4. 集齐三枚印记后，前往东北方月狼之巢。附近按 F 唤醒首领。
5. 击败月狼或在它残血破影后夺取影子，完成世界 1，解锁世界 2 和 3。
6. 打开「五境星图」，前往熔火裂谷或潮汐群岛。每个世界均需取得三枚印记，再击败当地首领。完成 2 和 3 后解锁风蚀遗迹；完成遗迹后解锁永夜王庭。

新任务中，清剿只计算标记敌群；航标与阀门靠近按 F 激活；遗迹机关按「日 → 月 → 星」操作，顺序错误会重置；王庭裂隙需先消灭附近守卫才能净化。方向标会引导到尚未完成的任务目标。

## 战利品、行囊与重访

每个世界有自己的四件物品，共 20 件。普通敌人有 28% 掉落率，精英 65%；每次成功完成任务必得一件随机物品；首次通关必得专属护符。奖励自动放入行囊。随机抽取允许重复，不保证每次都是不同物品。

在营地打开「行囊与护符」使用恢复生命、专注或净化梦蚀的补给；资源已满时不消耗对应补给。护符同时佩戴一件，重复护符不叠加。世界 1–5 的护符分别强化普攻、减伤、药剂、闪避与影技。

已通关世界可重访。每次从星图出发会重置该地图的敌人、任务、生命、祝福与影子等级；当前旅程已学会的技能及当前选择沿用。行囊、护符和世界解锁长期保留。重新开始整段旅程时，影子能力恢复初始配置。

地图中的深河只能走桥，浅沼减速，余烬灼伤。橙红实线圈和箭头是敌方危险范围与攻击方向；紫色交叉纹是必须走出的梦蚀区。预警内侧进度线表示攻击临近，落地后向内短线表示持续伤害。金色「袭击梦灯」箭头表示敌人正在攻击任务目标。

玩家技能使用薄荷绿、浅金和冰蓝开放光轨；敌方飞弹是橙红尖头。雾气位于角色下方，火花在角色附近淡出；关闭增强特效仍保留危险边界、方向、文字和敌人标记。

## 四种技能

每次只装备一种技能，鼠标瞄准后按 Q。初始学会突进和火焰，另外两种通过夺影解锁。

| 技能 | 效果 | 夺取这些敌人可学会 |
| --- | --- | --- |
| 突进 | 向前冲刺，斩穿敌人 | 狼、幽灵 |
| 火焰 | 扇形攻击，持续燃烧 | 火焰怪、蜂群 |
| 护盾 | 震击近敌，3 秒内格挡并反击一次 | 盾兵、巨人 |
| 影箭 | 三支穿透箭，远程攻击 | 弓手、镜魔 |

Tab 中点击卡片即可免费装备，切换保留当前冷却。四种技能共用 Q，不需要搭配附魔或回响。试炼场开放全部四种。

夺影自动学会对应技能，并恢复最多 25 生命、净化最多 10 梦蚀；只需选择「装备」或「保留当前技能」。重复夺影仍可恢复状态。使用中的技能累计击杀或夺影 7 / 18 次升至 Lv.2 / Lv.3，每级伤害 +22%、冷却减少 0.4 秒。

每次 Q 增加梦蚀，普攻不消耗。75 起治疗减半；首次满值进入 9 秒梦魇形态，结束降至 25；再次满值进入同化结局。药剂、夺影和营地休整可净化。梦魇结束不会封印任何技能。

旧存档自动将八种影子归入四种技能，保留各类最高等级与经验，旧第一槽决定当前技能。旧封存影子收入技能库。营地与世界进度继续沿用，加载不会直接重写原存档。

## 传送回城与冒险结算

探索任意世界时，按 B 或点击左下「传送回城」，原地保持 3 秒即可返回该世界的初始营地。法阵、光柱与倒计时显示传送进度；任务、战斗和梦魇状态都可使用。引导期间角色受到保护，当前任务计时暂停。移动、攻击、闪避、施放技能、夺影、喝药或打开面板会取消引导，再按 B 也可取消。回城不会自动补满生命。

回城后显示本轮实际冒险用时、击败数量、夺影次数，以及新增装备／补给的品质、效果和数量，还会展示新技能、祝福与探索收获。暂停和阅读面板不计时；读取营地继续会开始新一轮统计。战利品展示本轮获得总量，已使用的补给不再重复发放。未完成任务会结束，可以再次挑战，已获得物品全部保留。

营地状态与行囊在结算时自动保存。点击「关闭结算 · 返回首页」、右上关闭按钮或 Esc 返回初始界面，再点「继续营地存档」即可带着原装备、技能和进度继续。若浏览器写入失败，结算会提示并提供「重试保存」；关闭结算后仍可读取本页临时进度，但请不要刷新或关闭网页。

## 保存与继续

首次正式出发，在没有旧档时自动建立营地检查点。B 传送回城会自动结算并保存；步行回到营地仍可按 F 手动保存。休整之后还需要再次保存。

一个浏览器只有一个营地槽。通过教学或「直接进入森林」开始新旅程不会立刻覆盖旧档；从五境星图出发并点击「开始探索／踏入森林」会自动建立所选世界的新营地档。恢复营地只恢复上次检查点的敌人与探索进度。世界解锁、行囊、护符及通关记录独立自动保存，死亡不丢失已获得的物品。营地使用补给会同时保存资源状态。

同一趟远征中，读取旧档或重试任务不会重复领取已结算的随机掉落；从星图重新出发则能再次获得。旧森林存档可以继续读取。浏览器拒绝写入时会提示，当前页面仍可游玩，但关闭后可能无法保留新进度。

请始终使用同一浏览器、同一个文件入口。网页地址和本地文件、不同副本的存储可能互不相通；移动或重命名便携 HTML 后，部分浏览器可能不再显示旧档。浏览器无痕模式、禁止本地存储或清理网站数据，可能让存档无法保留。

## 设置与常见问题

- 右上齿轮：独立调节音乐、音效、场景亮度，开关震动与「增强光影、粒子与界面动画」。关闭增强效果会减少雾气和粒子，保留技能与危险提示；系统的减少动态效果偏好也会减少动画。
- 初次玩可选「旅人」：玩家受到伤害降低 35%，不改变梦灯耐久。默认「猎人」保持原版挑战。
- 切换窗口会暂停。按 Esc 或点继续恢复。
- 页面太小请放大窗口或点底部全屏；本版不支持手机虚拟摇杆。
- 没声音：点击一次开始或音符按钮，再检查设置与系统静音。音乐为本地实时合成，不需要网络。
- 卡路：深河请走桥，石墙不能穿过；任何地点都可按 B 静止 3 秒回城。

## 开发与重新打包

仅开发检查需要 Node.js，游玩不需要。

```text
npm run check
npm test
node tools/build.cjs
```

打包生成 release/ 中的独立 HTML。需要本地服务器预览时执行 npm start，打开终端显示的地址。
